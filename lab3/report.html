GET + POST + Cookie + Validation · HTML / CSS / JavaScript · Пятничная группа · Студент: Dinmukhamad Pakhriddinov

Открыть страницу входа Профиль Instagram

1. Цель работы

Сделать вход на сайт: при открытии сайта пользователь видит форму входа, а после успешного входа переходит на страницу профиля в стиле Instagram. В работе нужно использовать:

  • форму с методом POST и параметры GET в адресной строке;
  • cookie для хранения состояния входа и функции «Запомнить меня»;
  • валидацию введённых данных.

Технологии: только HTML, CSS и JavaScript. Сайт размещён на GitHub Pages.

2. Как работает сайт

  1. Пользователь открывает сайт: загружается index.html со страницей входа.
  2. Он вводит логин и пароль. JavaScript проверяет формат полей и сам пароль.
  3. При успехе в браузер записываются cookie, и пользователь переходит на profile.html (страница Instagram).
  4. profile.html сначала проверяет cookie. Если её нет, пользователь возвращается на index.html?error=auth.
  5. Кнопка «Выйти» удаляет cookie и открывает index.html?logout=1.
  6. Если пользователь уже вошёл и снова открывает сайт, его сразу перенаправляет на профиль.

3. Теория

GET и POST

GETPOST
Где передаются данныеВ строке URL: ?logout=1В теле HTTP-запроса
ВидимостьВидны в адресной строке и историиНе видны в URL
НазначениеПолучение страницы, неконфиденциальные параметрыОтправка данных формы (логин, пароль)
Как читать в JSnew URLSearchParams(location.search)Событие submit формы, form.elements
В этой работе?logout=1, ?error=auth, ?username=…Форма входа method="post"

Форма входа объявлена с method="post", потому что пароль нельзя передавать через GET: он попал бы в адресную строку и историю браузера. GitHub Pages отдаёт только статические файлы и не принимает POST-запросы, поэтому отправку формы перехватывает JavaScript (event.preventDefault()) и обрабатывает данные прямо в браузере.

Cookie

Cookie — небольшие данные, которые браузер хранит для сайта и отправляет с каждым запросом. В JavaScript они записываются и читаются через document.cookie.

CookieЗначениеСрокЗачем
ig_userлогинДо закрытия браузера, или 7 дней с «Запомнить меня»Признак входа. Без неё profile.html не открывается.
ig_rememberлогин7 днейПодставляет логин в форму после выхода.
ig_last_visitдата и время входа7 днейПоказывается в профиле: «Вы вошли как … · вход: …».

Атрибуты cookie: path — папка сайта (/web_labs/), max-age — срок жизни в секундах, SameSite=Lax — защита от отправки с чужих сайтов, Secure — только по HTTPS.

Валидация

Перед входом JavaScript проверяет поля и выводит ошибку под каждым неправильным полем:

  • Имя пользователя: обязательно, от 3 до 20 символов, только a–z A–Z 0–9 _ .
  • Пароль: обязателен, от 6 до 32 символов, минимум одна буква и одна цифра.
  • Если формат верный, пароль хешируется (SHA-256) и сравнивается с сохранённым хешем. Открытым текстом пароль в коде не хранится.
Ограничение статического сайта: весь код выполняется в браузере пользователя, поэтому такая защита учебная. В реальном проекте логин и пароль проверяет сервер, а cookie авторизации ставится с флагом HttpOnly, который из JavaScript установить нельзя.

5.1 Форма входа (index.html)

<form id="login-form" action="index.html" method="post"
      data-success="profile.html" novalidate>
    <input type="text" name="username" placeholder="Имя пользователя">
    <input type="password" name="password" placeholder="Пароль">
    <label><input type="checkbox" name="remember"> Запомнить меня</label>
    <button type="submit">Войти</button>
</form>

const params = new URLSearchParams(location.search);

// автозаполнение логина: из ?username= или из cookie

5.3 Обработка отправки POST-формы (login.js)

form.addEventListener('submit', async (event) => {
    event.preventDefault();             // сервера нет — обрабатываем в браузере
    const okUser = validateField('username');
    const okPass = validateField('password');
    if (!okUser || !okPass) return;

    const ok = await Auth.login(
        form.elements.username.value.trim(),
        form.elements.password.value,
        form.elements.remember.checked,
    );
    if (ok) {
        location.href = form.dataset.success;   // → profile.html
    } else {
        showFormError('Неверное имя пользователя или пароль.');
    }
});

5.4 Валидация (login.js)

const rules = {
    username(value) {
        if (value === '') return 'Введите имя пользователя.';
        if (value.length < 3 || value.length > 20) return 'Имя пользователя должно быть от 3 до 20 символов.';
        if (!/^[a-zA-Z0-9_.]+$/.test(value)) return 'Допустимы только латинские буквы, цифры, «_» и «.».';
        return '';
    },
    password(value) {
        if (value === '') return 'Введите пароль.';
        if (value.length < 6 || value.length > 32) return 'Пароль должен быть от 6 до 32 символов.';
        if (!/[A-Za-z]/.test(value) || !/\d/.test(value)) return 'Пароль должен содержать хотя бы одну букву и одну цифру.';
        return '';
    },
};

5.5 Cookie (auth.js)

function setCookie(name, value, maxAge) {
    let cookie = `${name}=${encodeURIComponent(value)}; path=${PATH}; SameSite=Lax`;
    if (maxAge !== undefined) cookie += `; max-age=${maxAge}`;
    if (location.protocol === 'https:') cookie += '; Secure';
    document.cookie = cookie;
}

async function login(username, password, remember) {
    const hash = USERS[username];
    if (!hash || (await sha256(password)) !== hash) return false;

    setCookie(AUTH_COOKIE, username, remember ? REMEMBER_TTL : undefined);
    setCookie(VISIT_COOKIE, new Date().toLocaleString('ru-RU'), REMEMBER_TTL);
    remember ? setCookie(REMEMBER_COOKIE, username, REMEMBER_TTL)
             : deleteCookie(REMEMBER_COOKIE);
    return true;
}

function logout() {
    deleteCookie(AUTH_COOKIE);   // max-age=0 — браузер удаляет cookie
}

5.6 Защита страницы профиля (profile.html)

<head>
    <script src="lab3/auth.js"></script>
    <script>
        if (!Auth.currentUser()) {
            location.replace('index.html?error=auth');
        }
    </script>
</head>

Проверка стоит в <head>, поэтому без входа страница не успевает показаться.

7. Скриншоты

8. Вывод

В ходе работы на сайт добавлен вход: сайт открывается со страницы входа, а после успешной авторизации пользователь попадает на страницу профиля в стиле Instagram. Форма отправляется методом POST, и эту отправку обрабатывает JavaScript, потому что на GitHub Pages нет сервера. GET-параметры в адресной строке используются для сообщений (?logout=1, ?error=auth) и автозаполнения логина (?username=). Состояние входа хранится в cookie, а «Запомнить меня» продлевает её до 7 дней и сохраняет логин для формы. Введённые данные проверяются по правилам, и под каждым неверным полем показывается ошибка. Все 20 тестовых сценариев пройдены.
